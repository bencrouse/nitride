# Sound studies 05 / extended network range

G's reported strength is that its behavior feels integrated into the voice. This
pass preserves that range and adds room to overdrive the same internal system.
There is no added post-distortion or separate noise source.

![Native Sound Studies 05](sound-studies-05.png)

## Listen

```sh
make studies
```

The app opens on Study 05, Rich FM, Monophonic lead.

- **A / FM reference:** unchanged source.
- **G / Current range:** the existing adaptive network.
- **H / Extended range:** the same network with additional upper-range stress.

G and H retain their own amounts when switching, defaulting to G 50% and H 25%.
Those positions are equivalent from a fresh voice. Start with them, then move H
to 50%, 60%, 75%, 90%, and 100%. Try short notes, velocity changes and the pad too.
Adaptive links remains available for both versions.

| H amount | Meaning |
| --- | --- |
| 0–50% | G's existing 0–100% range, compressed into the lower half. |
| 25% | Equivalent to G 50%. |
| 50% | Equivalent to G 100%. |
| 50–100% | Full G interaction plus increasing internal network stress. |

The mapping is checked numerically for both source profiles. Live switching also
crossfades independently evolving voice states, so momentary transitions need not
be identical. Offline paired files begin from the same conditions.

## What stress changes

Above the midpoint, stress increases:

- Phase coupling, reaching 4.5× the prior maximum coefficient.
- Conflicting preferred relative phases on the connections. Their adaptation still
  favours alignment, creating tension within the interacting system.
- Velocity-dependent transient drive into the phase dynamics.
- Shared phase feedback, including a nonlinear folded return signal.
- FM depth, reaching 3.4× the selected source index at full stress.

The carrier still uses the played note's frequency reference. Its reference pull
also increases, while the other nodes are allowed more aggressive interaction.
This does not guarantee a conventional perceived pitch at the extreme settings.

The folding occurs in the feedback return, affecting subsequent generation. The
output remains generated by the same oscillator network and passes through the
same decimation and output stages. G and H have separate state so crossfading
does not integrate one network twice or corrupt the original behavior.

The intended question is whether the upper range becomes usefully excessive while
still responding as one note-driven voice. Its sound and musical value need to be
judged by listening.

## Matched files

```sh
make render-studies-05
```

Writes 78 stereo 24-bit / 48 kHz WAVs under `build/sound-studies-05/`:

- Simple and rich FM sources.
- Lead, pad, and velocity phrases.
- Each group: A; G 50/100%; H 25/50/60/75/90/100%; and fixed-link H at 60/75/90/100%.

The G/H equivalence pairs are included explicitly. All variants of a source/phrase
share broadband RMS, with common headroom reduction if needed. The CSV records
applied gains and peaks. The live app uses fixed amount/source/adaptation-specific
compensation measured from these renders, rather than AGC. It is approximate
perceived-loudness matching, not LUFS normalization.

## Verification

Tests cover both sources, three sample rates, neutral return, block-size
independence, bounded high-polyphony rendering, note release, and lead pitch bends.
New checks verify G/H lower-half equivalence at several points and confirm that
upper-range stress changes the generated signal.

Native checks exercise G and full-stress H on the lead and pad, plus H with fixed
links. The final 48 kHz check completed with zero xruns and zero numerical faults.
