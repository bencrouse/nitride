# Reference preset exploration

**Current:** 53 sounds are finalized, including the subsequently approved Plastic
Hero, Budget Heaven and Sugar Teeth trio, unchanged from audition. See the
[factory workflow](../presets/factory/HOST_PRESETS.md) for the final selection and
[provenance](PRESET_PROVENANCE.md) for reference limitations. The following records
the exploration sequence; historical counts/pending questions are not current status.

Work begins with one sketch per category, reviewed in pairs:

1. Pads / basses — [batch 01, r1](../presets/review/batch-01/r1/README.md), then
   [focused r2 comparison](../presets/review/batch-01/r2/README.md).
2. Leads / sequence elements — [batch 02, r1](../presets/review/batch-02/r1/README.md),
   then [focused r2](../presets/review/batch-02/r2/README.md).
3. Physical materials / experimental — [batch 03, r1](../presets/review/batch-03/r1/README.md),
   then [focused Hollow Bronze r2](../presets/review/batch-03/r2/README.md).

Only then refine each category into two contrasting reference candidates, aiming
for 12 sounds before final factory-library voicing. Category boundaries describe
musical roles, not replacements for the expressive-network synthesis model.

## Tool

```sh
cmake --preset local-release
cmake --build --preset local-release --target nitride_preset_review
build/local-release/nitride_preset_review_artefacts/Release/nitride_preset_review \
  presets/review/batch-01/r1 build/preset-review/batch-01/r1
```

Use a new output directory for each render. The generic tool reads a versioned
`batch.json`, preset files and fixed-tempo 4/4 SMF performances. It writes portable
presets/MIDI, stereo 48 kHz / 24-bit preview/raw WAVs and a numeric report. It does
not install presets, open an audio device, alter factory patches or commit changes.
